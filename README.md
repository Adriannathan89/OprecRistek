Open Recruitment RISTEK Fasilkom UI Project

This project was developed for the Open Recruitment of RISTEK Fasilkom UI.
It is a full-stack web application built using modern technologies.

TECH STACK

Backend:
* NestJS
* TypeORM
* MySQL
* NPM
  
Frontend:
* Vite
* React
* NPM

Recommended Node.js version: v24

INSTALLATION GUIDE

Clone this repository to your local environment.

git clone <repository-url>
cd <project-folder>

Set up the environment file.

A template file is available as .env.example.
Copy it and rename it to .env, then configure the required variables (database credentials, port, etc.).

Install dependencies.

You need to install dependencies separately for both backend and frontend.

Backend:
1. cd backend
2. npm install

Frontend:
1. cd frontend
2. npm install

RUNNING THE APPLICATION

Start Backend:

* npm run start
  
or for development mode:

* npm run start:dev

Start Frontend:

npm run dev

DEVELOPMENT REQUIREMENTS

* Node.js v24 (recommended)
* MySQL installed and running
* Proper environment configuration
* npm

After completing all steps above, both backend and frontend should run successfully and the project is ready to use.
